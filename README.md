# Айдоочунун англисчеси — кирүү сервери

Кардар бир жолку **кирүү коду** менен өзүнүн **логин жана паролун** түзөт, анан ар дайым ошону менен кирет.
Аккаунт кардардын телефонуна (браузерине) байланат. Коддорду жана кардарларды **/admin** баракчасынан башкарасыз.

## Railway'ге коюу

1. **GitHub'та** жаңы репозиторий ачып, ушул папканын ичиндегилердин баарын жүктөңүз
   (`server.js`, `package.json`, `public/` папкасы).
2. **railway.app** → **New Project** → **Deploy from GitHub repo** → ошол репозиторийди тандаңыз.
3. Долбоордо **Variables** бөлүмүнө кошуңуз:
   - `ADMIN_PASSWORD` = өзүңүздүн татаал админ паролуңуз (аны эч кимге бербеңиз).
4. Маалымат жоголбошу үчүн **Volume** кошуңуз: сервисти оң баскыч менен басып → **Attach Volume** → Mount path: `/data`.
5. **Settings → Networking → Generate Domain** басыңыз. Шилтеме чыгат, мисалы `aidoochu.up.railway.app`.

## Колдонуу

- **Сиз (ээси):** `https://СИЗДИН-ШИЛТЕМЕ/admin` → админ паролу → «Код чыгаруу».
- **Кардар:** `https://СИЗДИН-ШИЛТЕМЕ/activate` → код + жаңы логин + пароль → «Активдештирүү».
- **Кийин кирүү:** `https://СИЗДИН-ШИЛТЕМЕ/login`.

## Админ панелиндеги баскычтар

- **Телефонду алмаштыруу**: кардар жаңы телефондон кире алат (эскиси чыгып калат).
- **Бөгөттөө / Ачуу**: кирүүнү токтотуу же кайра ачуу.
- **+30 күн**: кирүү мөөнөтүн узартуу.
- **Өчүрүү**: аккаунтту толук өчүрүү.

Коддорду «Түбөлүк» же мөөнөттүү (30 күн, 90 күн, 6 ай, 1 жыл) кылып чыгарсаңыз болот.
