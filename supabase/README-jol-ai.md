# «Жол Эсеп» — AI менен стейтмент окуу: орнотуу

> **Азыр өчүк.** Сайт толугу менен бекер, телефондун ичинде окуйт (PDF.js, Tesseract.js, таблица окугуч). AIны кийин күйгүзүү үчүн: ушул кадамдарды аткарып, `docs/eseb/app.js` ичинде `AI_ON=true` кылуу керек.

AI бөлүгү **ушул кадамдар аткарылмайынча өчүк**. Сайт мурункудай иштей берет жана «AI иштеп жатат» деп көрсөтпөйт.

## Эмне керек
1. **Anthropic API ачкычы** (Claude). Төлөмдүү: https://console.anthropic.com → Billing (баланс толтуруу) → API Keys → Create Key.
   Console'до **айлык чыгым лимитин** коюңуз (Settings → Limits).
2. **Supabase** — мурунтан бар долбоор (`ecfuobsggznwierzsgux`). Edge Functions акысыз пландын чегинде иштейт.

## Орнотуу (бир жолу)
1. Supabase → **SQL Editor** → `supabase/jol-ai.sql` файлынын ичин коюп, **Run**. Бул бир IP дарегинен бир күнгө жөнөтүлө турган суроо-талаптарды санайт (лимит 30). IP дарек ачык сакталбайт, анын хеши гана жазылат.
2. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor** → аты: `jol-ai` → `supabase/functions/jol-ai/index.ts` файлынын ичин толугу менен коюп, **Deploy**.
3. Ошол функциянын **Settings** бөлүмүндө **Enforce JWT verification** параметрин **өчүрүңүз**.
4. Supabase → **Edge Functions → Secrets** бөлүмүнө эки ачкыч кошуңуз:
   - `ANTHROPIC_API_KEY` = Anthropic'тен алган ачкыч
   - `JOL_AI_SALT` = каалаган узун кокус сап
5. Сайтты ачып, жергиликтүү окугуч толук окуй албаган стейтментти жүктөп көрүңүз. Колдонмо адегенде AI менен окууга макулдук сурайт.

API ачкычы **сайттын кодунда да, GitHub'да да жок**. Ал Supabase Secrets ичинде гана сакталат.

## Баасы (болжолдуу)
Модель: Claude Sonnet 5.5 — бир миллион токен үчүн киргизүү $2, чыгаруу $10 (https://platform.claude.com/docs/en/about-claude/pricing).
PDFтин бир бети ≈ 3,000–4,600 токен болот. 3 беттик стейтмент ≈ 15k киргизүү + ≈ 2k чыгаруу токен ≈ **$0.05**. Эсеп дал келбей, документ экинчи жолу окулса, ≈ **$0.10** чейин чыгат.
Жергиликтүү окугуч стейтментти өзү толук окуп, салыштыруу дал келсе, AI чакырылбайт жана акча коротулбайт (мисалы, ARAVAN стейтменти).

## Иштөө тартиби
1. Телефондогу жергиликтүү окугуч (PDF тексти, OCR, Excel/CSV) окуйт. Gross, кармоолордун жалпы суммасы жана Net Pay толук дал келсе, стейтмент дароо сакталат.
2. Дал келбесе жана AI орнотулган болсо, айдоочудан макулдук суралат. Андан кийин файл серверге, сервер аркылуу Claude'га жөнөтүлөт. Claude таблицанын түзүлүшүн өзү түшүнүп, JSON кайтарат.
3. Колдонмо ар бир сумманы өзү кайра эсептеп, стейтменттеги жыйынтыктар менен салыштырат: Net Pay, кармоолордун жалпы суммасы, Gross жана рейстердин суммасы.
4. Баары дал келсе, автоматтык сакталат. Дал келбесе, айырмасы көрсөтүлүп, AI документти кайра окуйт (2-жолу).
5. Ошондо да дал келбесе, **эч нерсе сакталбайт**: «Автоматтык окуу мүмкүн болгон жок» деп себептери көрсөтүлөт. Каалоого жараша гана кол менен карап чыгууга болот.
6. Маанисин документтен аныктоо мүмкүн болбогон кармоо (мисалы, «DK DEBT») чыгаша болуп кошулбайт, «түрү аныкталган жок» деп белгиленет.

## Тесттер
- `node docs/eseb/tests.js`: эсептөө, окугуч жана AI жообун текшерүү. AI жооптору жасалма.
- `node supabase/functions/jol-ai/test.mjs`: сервер. Anthropic жасалма, тармак жана ачкыч керек эмес.
