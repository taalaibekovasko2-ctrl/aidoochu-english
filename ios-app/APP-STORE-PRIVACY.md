Купуялуулук саясатынын URL'и: `https://taalaibekovasko2-ctrl.github.io/aidoochu-english/privacy.html`

**Data Used to Track You:** жок (No).

**Data Linked to You:** жок. Аккаунт жок, бардык ID'лер кокус жана адамга байланбайт.

**Data Not Linked to You:**

| Apple'дагы категория | Эмне | Эмне үчүн (Purpose) |
|---|---|---|
| Identifiers → User ID | лиганын кокус оюнчу ID'си | App Functionality |
| User Content → Gameplay Content | лигадагы ат (ник), упай, деңгээл, дуэль | App Functionality |
| User Content → Other User Content | даттанылган ат | App Functionality |
| Usage Data → Other | СНГ тамак-аштарын издөөдөгү шаардын аты | App Functionality |

**Purchases:** Apple аркылуу. Иштеп чыгуучу төлөм маалыматын албайт, ошондуктан белгиленбейт
(Apple'дын өзү иштеткен маалымат кошулбайт).

**Белгиленбейт:** GoatCounter. Ал сайтта гана бар, iPhone колдонмосунда өчүрүлгөн.
Үн. Ал телефондо иштейт, эч нерсе жөнөтүлбөйт.

**Age rating:** 4+. Колдонуучу жазган ат башкаларга көрүнөт, ошондуктан суроодо
«User-generated content: Yes» деп белгиленет. Чыпка, даттануу жана бөгөттөө бар.

**Колдонуучу жазган мазмун (1.2):** жаман сөз чыпкасы (`nameOk`), ар бир оюнчуга «⋯ → Даттануу / Бөгөттөө»,
даттануулар `league_reports` таблицасында (`supabase/league-report.sql`), 24 сааттын ичинде карап чыгуу,
байланыш email'и колдонмодо көрсөтүлөт.
