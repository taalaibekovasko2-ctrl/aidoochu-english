# Aidoochu English — iPhone сыноо версиясы (Capacitor)

Бул папка iPhone колдонмосунун долбоору. **Сайт (`docs/`) өзгөрбөйт**: колдонмо куралган сайын сайттын
`docs/index.html` файлын жана сүрөттөрүн өзүнө көчүрүп алат. Колдонмонун ичине кирген сайттын көчүрмөсүнө
гана iPhone үчүн өзгөртүүлөр кошулат (`scripts/build-www.mjs`, `src/ios-shim.js`).

## Куруу

```
cd ios-app
npm ci
npm run sync        # docs/ → www/ → ios/App (Xcode долбоору)
```
GitHub Actions: `.github/workflows/ios-build.yml`. Ал iOS Simulator үчүн гана курайт: кол коюлбайт, Apple аккаунту
колдонулбайт, эч нерсе жарыяланбайт, жана симулятордон скриншот алат. Репозиторий ачык болгондуктан, курагыч бекер.

## Камдык көчүрмө жана артка кайтаруу

- Сайт `main` бутагынан ачылат. Бул иш `main`'ге тийбейт, өзүнчө `claude/ios-capacitor` бутагында турат.
- Ишти баштоодо сайттын абалы: `main` = `332b9f0f4d36c04eed2ed6942cc5f0dafa74d7dc`. Бул коммит Git тарыхында
  түбөлүк сакталат. Каалаган убакта ушул абалга кайтса болот: `git checkout 332b9f0 -- docs/`.
- Артка кайтаруу: iOS ишин толугу менен таштоо үчүн `claude/ios-capacitor` бутагын өчүрүү жетиштүү, сайтка эч таасири жок.
  Эгер кийин бир нерсе `main`'ге кошулуп, сайт бузулса, ошол кошуунун коммитин `git revert` кылуу же GitHub'дагы
  pull request'тин «Revert» баскычын басуу жетиштүү. Сайт мурунку абалына 1–2 мүнөттө кайтат.
- Колдонуучулардын маалыматы (прогресс, коддор) сервер-де эмес, ар бир адамдын өз телефонунда (localStorage) сакталат.
  Бул долбоор аларга тийбейт жана эч нерсени өчүрбөйт.

## Мурда сатып алынган коддор жана прогресс (2-этап: даяр, сыноо бутагында)

Код = сатуучунун ECDSA кол тамгасы, ал `"AE1:" + түзмөктүн ID'си` деген текстке коюлат. Колдонмого ошол эле ID өтсө,
эски код кайра төлөбөй эле иштейт.

- **Сайт** (`docs/index.html`, бул бутакта гана, `main`'ге кошула элек): коду же прогресси бар колдонуучуга гана
  «📲 iPhone колдонмосуна көчүрүү» баскычы көрүнөт. Ал `AEX1.` менен башталган кодду түзөт: `{v, did, act, game, lang, promoOk, t}`.
  Код эч жакка жөнөтүлбөйт, телефондогу маалымат өзгөрбөйт, ал жөн гана көчүрүү үчүн көрсөтүлөт.
- **Колдонмо** (`src/ios-shim.js`): кулпу терезесинде «🔁 Сайтта сатып алгансызбы?» талаасы бар. Код коюлганда ID, код,
  прогресс, тил жана промокод колдонмого жазылат. Туура эмес код четке кагылат.
- Текшерилди: сайтта 450 XP, 3/110 деңгээл, RU тили жана ачык абал болчу. Колдонмого ошол бойдон өттү, сайттагы маалымат өзгөргөн жок.
- Эскертүү: көчүрүү коду сатып алууну ачат. Ошондуктан колдонуучуга «эч кимге бербеңиз» деп жазылган.

## Лигада даттануу жана бөгөттөө (Apple 1.2)

- Ар бир башка оюнчунун жанында **⋯** баскычы турат, андан «🚩 Даттануу» же «🚫 Бөгөттөө» тандалат.
  Бөгөттөлгөн оюнчу ошол телефондо жашырылат (`lgblk`). Даттануу `league_report` RPC'сине жөнөтүлөт,
  ал эми оюнчу ошол замат бөгөттөлөт. Интернет жок болсо, email көрсөтүлөт.
- Жаман сөз чыпкасы (`nameOk`, EN/RU/KG/KZ): уят ат сакталбайт. Башкалардын аттарында ал «А***» болуп көрүнөт.
  Кадимки аттар (Dickson, Себлякан, Котакбаев, Сукачев…) бөгөттөлбөйт, текшерилди.
- Сервер: `supabase/league-report.sql` файлын Supabase SQL Editor'до **бир жолу** иштетүү керек (таблица + функция +
  админ үчүн `league_reported_names` көрүнүшү). Ал иштетилгенге чейин даттануу жөнөтүлбөйт, бирок бөгөттөө иштей берет.

## Apple In-App Purchase (2-этап: сыноо режиминде даяр, баа коюлган эмес)

- Плагин: `@capgo/native-purchases` (бекер, StoreKit 2). Продукт: `com.aidoochu.english.full`, Non-Consumable.
- Кулпу терезеси (колдонмодо гана): «🍎 Apple аркылуу толук ачуу», андан кийин **Сатып алуу** жана **Сатып алууларды калыбына келтирүү**.
  Баа коддо жок. Ал App Store Connect'тен келет (`priceString`). Продукт азырынча жок болгондуктан,
  «Apple'да азырынча даяр эмес (сыноо версиясы)» деп жазылат.
- Сатып алгандан кийин колдонмо интернетсиз да ачык болот (`iapOk`). Ачылганда Apple'дан кайра текшерилет,
  акча кайтарылган болсо, жабылат. Жаңы телефондо «Калыбына келтирүү» же автоматтык текшерүү иштейт.
- Колдонмодо WhatsApp, телефон жана «ID'ни сатуучуга жөнөтүү» бөлүгү жашырылган. Сайтта мурдагыдай калат.
- Тесттик Apple жообу менен текшерилди: сатып алуу, кайра ачуу, калыбына келтирүү, «сатып алуу табылган жок» жана плагинсиз абал.
- Чыныгы Sandbox'то текшерүү үчүн керек: Apple Developer, App Store Connect'те продукт жана Sandbox тестер.
