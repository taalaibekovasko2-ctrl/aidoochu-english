# Aidoochu English — iPhone сыноо версиясы (Capacitor)

Бул папка iPhone колдонмосунун долбоору. **Сайт (`docs/`) өзгөрбөйт**: колдонмо куралган сайын сайттын
`docs/index.html` файлын жана сүрөттөрүн өзүнө көчүрүп алат. Колдонмонун ичине кирген сайттын көчүрмөсүнө
гана iPhone үчүн өзгөртүүлөр кошулат (`scripts/build-www.mjs`, `src/ios-shim.js`).

## Куруу

```
cd ios-app
npm ci
npm run sync        # docs/ → www/ → ios/App (Xcode долбоору)
```
GitHub Actions: `.github/workflows/ios-build.yml`. Ал iOS Simulator үчүн гана курайт: кол коюлбайт, Apple аккаунту
колдонулбайт, эч нерсе жарыяланбайт, жана симулятордон скриншот алат. Репозиторий ачык болгондуктан, курагыч бекер.

## Камдык көчүрмө жана артка кайтаруу

- Сайт `main` бутагынан ачылат. Бул иш `main`'ге тийбейт, өзүнчө `claude/ios-capacitor` бутагында турат.
- Ишти баштоодо сайттын абалы: `main` = `332b9f0f4d36c04eed2ed6942cc5f0dafa74d7dc`. Бул коммит Git тарыхында
  түбөлүк сакталат. Каалаган убакта ушул абалга кайтса болот: `git checkout 332b9f0 -- docs/`.
- Артка кайтаруу: iOS ишин толугу менен таштоо үчүн `claude/ios-capacitor` бутагын өчүрүү жетиштүү, сайтка эч таасири жок.
  Эгер кийин бир нерсе `main`'ге кошулуп, сайт бузулса, ошол кошуунун коммитин `git revert` кылуу же GitHub'дагы
  pull request'тин «Revert» баскычын басуу жетиштүү. Сайт мурунку абалына 1–2 мүнөттө кайтат.
- Колдонуучулардын маалыматы (прогресс, коддор) сервер-де эмес, ар бир адамдын өз телефонунда (localStorage) сакталат.
  Бул долбоор аларга тийбейт жана эч нерсени өчүрбөйт.

## Мурда сатып алынган коддор жана прогресс

Код = сатуучунун ECDSA кол тамгасы, ал `"AE1:" + түзмөктүн ID'си` деген текстке коюлат (`checkCode`). Колдонмонун
ID'си башка болот, ошондуктан эски код колдонмодо өзүнөн-өзү иштебейт. Эки жол бар:

1. **Сайтты өзгөртпөй, азыр эле иштейт:** колдонмодо кулпу терезеси жаңы ID'ни көрсөтөт. Кардар аны сатуучуга
   жөнөтөт, сатуучу жаңы ID'ге бекер жаңы код берет (жашыруун ачкыч сатуучуда, мурдагыдай). Прогресс бул жол менен өтпөйт.
2. **Толук көчүрүү (2-этап, сайтка уруксатыңыз менен бир баскыч кошулат):** сайтта «iPhone колдонмосуна көчүрүү»
   баскычы `AEX1.` менен башталган көчүрүү кодун берет. Анын ичинде `{did, act, game, lang, promoOk}` болот.
   Колдонмонун кулпу терезесинде «🔁 Сайтта сатып алгансызбы?» деген талаа **даяр**. Ага код коюлганда эски ID,
   код, прогресс жана тил колдонмого жазылат, ошондуктан эски код кол тамга боюнча дароо иштейт.
   Колдонмо бөлүгү даяр жана текшерилди. Сайт бөлүгү азырынча жасалган жок (сайтты өзгөртпө деген шарт).

## Apple In-App Purchase планы (азырынча төлөм иштетилбейт)

- Продукт: `com.aidoochu.english.full`, **Non-Consumable** (бир жолу сатып алынат, түбөлүк). Баасын сиз тандайсыз.
- Плагин: бекер, ачык `@capgo/native-purchases` (StoreKit 2) же `cordova-plugin-purchase`. RevenueCat'ке муктаж эмес.
- Кулпу терезеси: «Толук ачуу — $X (Apple)» жана **«Сатып алууларды калыбына келтирүү»** баскычтары (Apple талап кылат).
  «Сайттан көчүрүү» талаасы эски кардарлар үчүн калат.
- Ачуу: сатып алуу тастыкталса `__ok = true`. Код системасы колдонмодо экинчи жол катары калат (мурда сатып алгандар үчүн).
- Apple'дын үлүшү: App Store Small Business Program боюнча 15%.
- Текшерүү: App Store Connect'те Sandbox тестер аккаунту менен, акча алынбайт.
- Apple'га текшерүүгө жөнөтүүдөн мурда: Paid Apps келишими, салык жана банк маалыматтары App Store Connect'те толтурулат.

## Купуялуулук жана коопсуздук (текшерүүнүн жыйынтыгы)

- ✔ Репозиторийде коддорго кол коюучу жашыруун ачкыч жок, колдонмодо ачык ачкыч гана бар.
- ✔ Аккаунт жок, сырсөз жок. Ошондуктан «аккаунтту өчүрүү» талабы бул колдонмого тиешелүү эмес.
- ⚠ `privacy.html` «маалымат чогултпайбыз» дейт. Бирок лига жана дуэль серверге (Supabase) **кокус ID + оюнчу аты +
  упай** жөнөтөт. Сервер IP'ни да көрүшү мүмкүн. Текстке ушуну кошуу керек. App Store'догу «App Privacy»:
  *User ID* (кокус, адамга байланбайт), *Gameplay Content / Name* (лига үчүн), «трекинг жок».
- ⚠ Лига аттарды баарына көрсөтөт (Apple 1.2): даттануу жана бөгөттөө баскычтары, жаман сөз чыпкасы, же аттарды
  тизмеден тандоо керек. Бул 2-этапта колдонмо үчүн жасалат.
- ⚠ Админ PIN `admin_ok` RPC'сине жөнөтүлөт. Колдонмодо жашырылган, бирок сервер тарапта аракет санын чектөө сунушталат.
- Колдонмо жалаң HTTPS колдонот, шифрлөөнүн өзүнүн алгоритми жок: `ITSAppUsesNonExemptEncryption = false` коюлду.

6. Купуялуулук баракчасынын жаңыланган тексти жана «Support URL» (GitHub Pages'те бекер).
7. TestFlight'та ички тестерлер (100 адамга чейин) Apple'дын текшерүүсүз тез эле сынай алат. Тышкы тестерлер
   (10 000 адамга чейин) Apple'дын жеңил текшерүүсүнөн өтүшү керек.
